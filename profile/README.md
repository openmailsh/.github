# OpenMail

Email inbox infrastructure for AI agents.

[openmail.sh](https://openmail.sh) · [docs.openmail.sh](https://docs.openmail.sh) · [console.openmail.sh](https://console.openmail.sh)

---

## Open source

| Repo | Description |
|------|-------------|
| [cli](https://github.com/openmailsh/cli) | `openmail` CLI: inboxes, sending, policy, live events |
| [openmail-sdk-typescript](https://github.com/openmailsh/openmail-sdk-typescript) | TypeScript SDK |
| [hermes-plugin](https://github.com/openmailsh/hermes-plugin) | Hermes Agent plugin: an email address for your agent |
| [openclaw-plugin](https://github.com/openmailsh/openclaw-plugin) | OpenClaw channel plugin, same design |
| [skills](https://github.com/openmailsh/skills) | Agent skill for the CLI and API, bundled into both plugins |
| [docs](https://github.com/openmailsh/docs) | Source for docs.openmail.sh |

Contributions welcome. Check the `CONTRIBUTING.md` in each repo to get started.
